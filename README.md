# CMMM (Cut Movie & Merge Movie Studio)
**スマート型切り替え式・無劣化動画編集ツール**

Windows Movie Maker の直感的な操作感（ストーリーボード・ファイルドロップ・プレビュー分割）と、CutMovie（無劣化カット）および UniteMovie（無劣化結合）のスピードを統合した動画編集ツールです。

---

## 主な特徴

- **📁 エクスプローラーから直接ドラッグ＆ドロップ**:
  動画ファイルを画面またはストーリーボードにポイッと放り込むだけで一括登録。上書きされることなく確実に末尾に追加されます。
- **⚡ 爆速読み込み (0.05秒)**:
  動画追加時はメタデータのみ瞬時に取得し、サムネイルはバックグラウンドスレッドで非同期生成。何十本ドロップしてもUIが一切フリーズしません。
- **🎬 Windowsネイティブの確実な動画再生**:
  `QMediaPlayer` + `QVideoWidget`（Windows DirectShow/WMF）により、MP4/H.264/AAC動画が100%スムーズに再生・シーク可能です。
- **🛡️ 無劣化フォーマット互換性チェック（UniteMovie仕様）**:
  1本目の動画の解像度・コーデック・音声形式を基準とし、合わない動画は「⚠️ 形式不一致」と理由を表示して自動で除外するため、結合エラーや破損を100%防止。
- **🎞️ WMM風 ストーリーボード**:
  サムネイルカードをマウスで掴んでスイスイ並び替え。`Delete` キーで選択クリップをOS直結で確実に削除可能。
- **✂️ 切り出したクリップの再編集（非破壊トリミング）**:
  シークバー上の左右ハンドルをドラッグして In点/Out点 を何度でも伸縮・調整可能。`S` キーで現在位置での分割も一発。
- **⚡/🎯 スマート型切り替え式**:
  - **完全無劣化モード (Keyframe)**: キーフレームにスナップし、再エンコード 0% で爆速出力。
  - **スマートカットモード (Frame-Accurate)**: 1フレーム・ミリ秒単位で精密にカットし、境界GOPのみ再エンコードして中間は無劣化コピー。
- **🔌 編集UIと実行エンジンの完全分離**:
  編集結果は軽量レシピ（JSON）として保存可能。重い動画処理は独立したCLIエンジンがバックグラウンドで高速実行。

## 起動方法

### 1. ダブルクリックで起動（おすすめ）
- [**CMMM.pyw**](file:///c:/Projects_Apps/my_Projects/CMMM/CMMM.pyw) をエクスプローラーからダブルクリックするだけで、黒いコンソール画面を出さずに直接起動できます。

### 2. コマンドラインから起動する場合
```bash
python run_editor.py
```
Windows 11 Fluent風 ダークテーマの軽快なネイティブ編集ウィンドウが立ち上がります。

### 2. 実行CLIエンジン（バッチ処理）の起動
保存したレシピ（JSON）から直接CLIで動画を出力することも可能です。
```bash
python run_engine.py recipe.json
```

## ショートカットキー一覧

| キー | 操作 |
| :--- | :--- |
| `Space` | 再生 / 一時停止 |
| `S` | 現在位置でクリップ分割 (Split) |
| `I` | 現在位置をクリップの開始点 (In点) に設定 |
| `O` | 現在位置をクリップの終了点 (Out点) に設定 |
| `Delete` / `Backspace` | 選択中のクリップを削除 |
| `←` / `→` | 1フレームコマ戻し / コマ送り |
| `Shift + ←` / `Shift + →` | 前のキーフレーム / 次のキーフレームへジャンプ |
